# إنجاز نافس

منصة تدريبية مستقلة للاستعداد لاختبارات نافس الوطنية. تضم ٣٠٠ سؤال محاكٍ في الرياضيات والقراءة والعلوم، مصنفة حسب الصف والمعيار والمستوى المعرفي، مع حسابات للطلاب والمعلمين والمدارس ولوحة تحكم للإدارة.

## الصفحات

| الصفحة | الوصف |
|---|---|
| `index.html` | الصفحة الرئيسية والاختبارات المحاكية (تعمل دون تسجيل) |
| `register.html` | إنشاء حساب طالب أو معلم أو مدرسة |
| `login.html` | تسجيل الدخول واستعادة كلمة المرور |
| `dashboard.html` | لوحة التحكم، وتختلف حسب نوع الحساب |

## الأدوار والصلاحيات

| الدور | التفعيل | ماذا يرى ويفعل |
|---|---|---|
| طالب | مباشرة | تُحفظ نتائج اختباراته، ويرى مستواه في كل معيار وسجل اختباراته |
| معلم | بموافقة المدرسة أو الإدارة | يرى طلاب مدرسته ونتائجهم وأداءهم حسب المعايير |
| مدرسة | بموافقة الإدارة | تقبل أو توقف معلميها وطلابها، وترى تقارير المدرسة كاملة |
| مدير النظام | يُعيَّن يدوياً (انظر الخطوة ٧) | يدير كل المستخدمين والمدارس، ويقبل الطلبات، ويغيّر الأدوار، ويصدّر البيانات بصيغة CSV |

تُفرض هذه الصلاحيات في قاعدة البيانات نفسها عبر الملف `firestore.rules`، وليس في الواجهة فقط.

## خطوات الربط بـ Firebase

1. **أنشئ مشروعاً:** ادخل إلى https://console.firebase.google.com واضغط **Add project**.
2. **فعّل تسجيل الدخول بالبريد:** من **Build ← Authentication ← Get started ← Sign-in method** فعّل **Email/Password**.
3. **أنشئ قاعدة البيانات:** من **Build ← Firestore Database ← Create database** اختر **Production mode** وأقرب منطقة متاحة.
4. **انشر قواعد الأمان:** من **Firestore Database ← Rules** احذف المحتوى الموجود، والصق محتوى الملف `firestore.rules` كاملاً، ثم اضغط **Publish**.
5. **انسخ إعدادات الربط:** من **Project settings (⚙️) ← General ← Your apps** اضغط أيقونة الويب `</>` وسجّل تطبيقاً، ثم انسخ القيم إلى الملف `firebase-config.js` وارفعه إلى المستودع. هذه القيم ليست سرية، والحماية تتم بقواعد الأمان.
6. **اسمح بنطاق الموقع:** من **Authentication ← Settings ← Authorized domains** أضف `tqiti.github.io`.
7. **عيّن أول مدير:**
   - سجّل حساباً من الموقع نفسه (كطالب مثلاً).
   - افتح **Firestore Database ← Data ← users** وافتح المستند الذي يحمل بريدك.
   - عدّل الحقل `role` إلى `admin` والحقل `status` إلى `active`.
   - سجّل الدخول مجدداً، وستظهر لك لوحة تحكم الإدارة. بعدها يمكنك ترقية مدراء آخرين من اللوحة نفسها.

## بنية البيانات

- `users/{uid}`: الاسم، البريد، الدور، الحالة، المدرسة، الصف أو المادة.
- `schools/{uid}`: اسم المدرسة، المدينة، المرحلة، الحالة. المدارس المفعّلة فقط تظهر في قائمة التسجيل.
- `results/{id}`: نتيجة كل اختبار مع الأداء في كل معيار ومستوى معرفي.

## ملاحظات

- لا يمكن حذف حساب الدخول من اللوحة، لذلك تُستخدم حالة «موقوف» بدلاً من الحذف.
- تعرض لوحة الإدارة أحدث ١٠٠٠ نتيجة.
- بنك الأسئلة موجود في المجلد `questions/`، ويمكن إضافة أسئلة جديدة بالصيغة نفسها.
